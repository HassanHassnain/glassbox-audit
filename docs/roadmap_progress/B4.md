## How

The raw Hugging Face adapter now exposes `_forward_logits`, which preserves its existing hook
semantics. TransformerLens overrides this method with `run_with_hooks` and captures
`blocks.{layer}.hook_out` with `run_with_cache`. nnsight overrides it with a local trace, edits the
decoder-block output, and saves logits from `lm_head`; activation collection saves the requested
block outputs in one trace per prompt. Both adapters reuse the same tokenizer, scorer, model
weights, held-out splits, interventions, controls, and artifact writer as the original backend.

Package verification uses resources inside `glassbox_audit.resources`, so the installed smoke does
not depend on `configs/` or `data/` from a checkout. The verifier works under `artifacts/`, builds
without isolation from the declared local release environment, and leaves no distribution upload
side effect.
