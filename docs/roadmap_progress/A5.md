# A5 Progress Note

## Scope

Implemented A5 from `ROADMAP_AMBITIOUS_GLASSBOX.md`: head-level shortlisting and held-out verification for attention-output head slices, emitted as a frozen-artifact analysis command.

## Implemented

- Added `HeadSliceIntervention` for applying an intervention to one attention-output head slice.
- Added Hugging Face model helpers for:
  - inferring attention head count;
  - collecting final-token attention-output head slices;
  - evaluating interventions on one attention-output head slice.
- Added `glassbox_audit.head_path`.
- Added `glassbox head-path`.
- The A5 analysis:
  - loads a frozen audit artifact;
  - shortlists heads using train-only projection effect along the mean-difference refusal direction;
  - verifies the shortlist on held-out records with head-slice direction ablation;
  - also runs projection patching to the train benign mean;
  - applies Benjamini-Hochberg correction across verified head-ablation tests;
  - writes `head_path_analysis.json`;
  - writes a compact snapshot under `results/head-path/`;
  - can render a Markdown table with `--output-table`.
- Added `docs/HEAD_PATH_ANALYSIS.md`.
- Added README and methodology references.
- Added `make head-path`.
- Added hook coverage for selected-head slice intervention behavior.

## How

The implementation reuses the existing frozen artifact wall: records, baseline outputs, thresholds, train activations, and the mean-difference direction come from the artifact. Head candidates are ranked only on train records. The held-out test split is used only for verification rows. The generic Hugging Face implementation treats the attention module output as `num_attention_heads` contiguous slices in hidden space.

## Goal Completion

The A5 implementation goal is complete for the generic attention-output head-slice path: command, artifact schema, shortlist, held-out verification, BH correction, docs, and tests. It does not claim architecture-specific pre-output attention-head path patching.

The full analysis was subsequently run against `artifacts/qwen-real-audit`. Five layer-27 heads
survived BH correction (heads 10, 3, 9, 11, and 8), but their held-out harmful-score effects were
small: estimates ranged from `-0.000059` to `-0.000364`. This settles the configured generic
head-slice test without establishing a practically large or architecture-specific circuit.
