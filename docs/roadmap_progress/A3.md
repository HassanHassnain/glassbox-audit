## How

The runner derives all requested source-checkpoint directions first and unloads each source model.
It then loads the endpoint once, selects the scoring threshold on endpoint validation records, and
tests every frozen direction on held-out pairs. This staging avoids keeping source and endpoint 7B
models in GPU memory together. The evidence distinguishes Pythia final-base representation transfer
from OLMo final-instruct causal transfer.

## Goal Completion

A3 is complete for implementation and full-scale execution. All twelve frozen cells
completed: six Pythia-410M checkpoints tested at the final base endpoint and six
OLMo-7B-0724 checkpoints tested at the official instruct endpoint. Every source
checkpoint passes the preregistered representation-separation rung, but none passes
the complete endpoint-transfer bundle.

Pythia directions become increasingly aligned with the final base model late in
training. The strongest target effect is `-0.0364` at step 128000 with cosine
`0.961`, but its nominal random-control `p=.04` becomes `q=.096` after correction
across the full twelve-cell family. This is suggestive representation continuity,
not a preregistered transfer pass.

OLMo selects layer 23 at 4B tokens and layer 31 thereafter. Endpoint direction
cosines range from `-0.019` to `0.110`, and harmful-score effects range only from
`-0.00099` to `+0.00109`. The 1258B cell has nominal `p=.04` but `q=.096`; all six
OLMo cells fail the frozen transfer criteria.
