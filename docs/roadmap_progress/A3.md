## How

The runner derives all requested source-checkpoint directions first and unloads each source model.
It then loads the endpoint once, selects the scoring threshold on endpoint validation records, and
tests every frozen direction on held-out pairs. This staging avoids keeping source and endpoint 7B
models in GPU memory together. The evidence distinguishes Pythia final-base representation transfer
from OLMo final-instruct causal transfer.
