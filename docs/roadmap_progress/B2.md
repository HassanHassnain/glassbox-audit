## How

Artifact-comparison mode builds B1-style audit cards for both artifacts and compares their rung pass states. This supports architecture-changing upgrades where frozen source tensors may not be dimension-compatible with the new model.

Model-swap mode is the CI-style drift monitor. It loads the source artifact's frozen directions, SAE, selected features, threshold, records, and validation-selected scales, swaps only the model identity/config, and reruns the intervention evaluations. It fails closed if the new model hidden size does not match the frozen handles.
