## How

The runner reloads the frozen model configuration, mean direction, target layer, source effect, and
behavior threshold from an existing audit artifact. It keeps all row-level scores in memory only,
computes family-level comparisons and controls, then writes aggregate evidence after a recursive
content check. The local shifted corpus is explicitly ignored by Git.
