## How

Top-k budgets use only train SAE feature effect sizes. L1 budgets fit logistic weights on train SAE activations only, rank features by absolute weight, and build a decoder-space direction for each budget. All frontier rows are held-out test evaluations against the same baseline outputs as the main causal tests.
