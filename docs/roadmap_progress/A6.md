# A6 Progress Note

## Scope

Implemented A6 from `ROADMAP_AMBITIOUS_GLASSBOX.md`: equivalence testing, power analysis, and pair-level bootstrap support for held-out causal audit statistics.

## Implemented

- Added grouped bootstrap support in `glassbox_audit.stats`, with `paired_delta_ci(..., group_ids=...)` for matched-pair resampling.
- Switched core intervention comparisons, direct method comparisons, path-component summaries, and Phase 5 statistical summaries to use `pair_id` bootstrap groups.
- Added TOST equivalence tests for SAE feature ablation versus mean-difference and linear-probe ablations.
- Added one-sided inferiority tests asking whether SAE is worse than each simple baseline by a configured margin.
- Added paired normal-approximation power planning with default assumptions: effect size `0.05`, pair-delta SD `0.4`, alpha `0.05`, target power `0.8`, and target n `500` prompt pairs.
- Added frozen A6 settings to `EvaluationConfig` and real-audit validation.
- New audit runs write `equivalence_analysis.json`, include A6 status in `summary.json`, and record the statistical protocol in `protocol.json`.
- `glassbox statistical-tests` now includes A6 equivalence and power analysis for internal artifacts.
- Reports and publication tables surface the A6 results when `equivalence_analysis.json` exists.

## How

The implementation treats SAE-minus-baseline harmful-score deltas as the comparison unit. Positive deltas mean SAE leaves a higher harmful refusal score after intervention, so the simple baseline suppresses more. Equivalence uses TOST with symmetric margins. Inferiority uses a one-sided normal test plus a pair-clustered bootstrap lower bound.
