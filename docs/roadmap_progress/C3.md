## How

The builder runs `python -m glassbox_audit.cli certify --artifacts artifacts/demo` so the demo does
not require a live model load. It captures stdout, writes the card JSON/HTML/PDF outputs, derives a
six-segment 90-second narration from the emitted card, writes WebVTT captions and a storyboard JSON,
and renders a captioned MP4 with local `ffmpeg` when available.
