## How

The builder scans roots for directories containing `summary.json`, `manifest.json`, and `interventions.json`. For each causal-test row it records model, behavior, method, SAE checkpoint metadata, target layer, held-out harmful-score delta, benign specificity delta, capability NLL delta, matched-control summary, verdict, readiness status, preregistration hash, and source-file hashes.

The generated HTML is a static table with no backend. The JSON is the canonical artifact for CI and review.
