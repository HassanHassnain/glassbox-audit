## How

The sweep keeps the existing audit pipeline as the execution unit. Each generated config sets validation-selected thresholds, train-only layer/feature discovery, the same steering scale grid, matched controls, and the fixed `samples_per_feature` rule. `model-sweep summarize` reads completed artifact directories when they exist; otherwise, it keeps each predeclared model visible as `unrun` so the grid cannot silently disappear.
